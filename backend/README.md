## О проекте

**СУРПП** — система для автоматизации планирования производства в кондитерском цехе.

### Назначение
- Учёт ингредиентов, оборудования и персонала
- Управление рецептурами и технологическими операциями
- Регистрация производственных заказов
- Контроль складских остатков и сроков годности
- Формирование производственного расписания

### Пользователь
> Инженер по производственному планированию кондитерского цеха

### Материалы

## База данных

> ✅ **Статус**: Реализовано. Модели, миграции и seed-данные готовы.

### Общая архитектура БД

```
СУРПП Database (PostgreSQL 13+)
│
├── Справочники
│   ├── ingredients       # Ингредиенты (сырьё)
│   ├── equipment         # Оборудование цеха
│   └── competences       # Квалификации сотрудников
│
├── Сотрудники
│   ├── employees         # Список кондитеров
│   └── employee_competences  # Связь сотрудник ↔ квалификация
│
├── Рецептуры
│   ├── recipes           # Изделия (торты, пирожные)
│   ├── recipe_ingredients # Состав рецептуры (M2M)
│   └── operations        # Технологические операции
│
├── Заказы
│   ├── orders            # Производственные заказы
│   └── order_items       # Позиции заказа (M2M)
│
├── Производство
│   ├── stock             # Складские остатки
│   └── schedule          # Производственное расписание
│
└── Связи: все внешние ключи с CASCADE-удалением
```

### Описание таблиц

#### Справочники

##### `ingredients` — Ингредиенты/сырьё
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `name` | String(100) | Название ингредиента | Unique, Not Null |
| `unit` | String(20) | Единица измерения (кг, л, шт) | Not Null |
| `shelf_life_days` | Integer | Срок годности в днях | Nullable |

##### `equipment` — Оборудование
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `name` | String(100) | Название оборудования | Unique, Not Null |
| `type` | String(50) | Тип (печь, миксер, холодильник) | Not Null |
| `quantity` | Integer | Количество единиц | Default=1, ≥1 |

##### `competences` — Квалификации
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `name` | String(100) | Название (напр. "Кондитер 3 разряда") | Unique, Not Null |
| `description` | Text | Описание компетенции | Nullable |

#### Сотрудники

##### `employees` — Сотрудники
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `full_name` | String(150) | ФИО сотрудника | Not Null |
| `is_active` | Boolean | Статус занятости | Default=True |

##### `employee_competences` — Связь сотрудник ↔ квалификация
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `employee_id` | Integer | Ссылка на сотрудника | FK → employees.id, CASCADE |
| `competence_id` | Integer | Ссылка на квалификацию | FK → competences.id, CASCADE |

#### Рецептуры

##### `recipes` — Изделия
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `name` | String(100) | Название изделия | Unique, Not Null |

##### `recipe_ingredients` — Состав рецептуры
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `recipe_id` | Integer | Ссылка на рецептуру | FK → recipes.id, CASCADE |
| `ingredient_id` | Integer | Ссылка на ингредиент | FK → ingredients.id, CASCADE |
| `quantity` | Float | Количество ингредиента | Not Null, >0 |

##### `operations` — Технологические операции
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `recipe_id` | Integer | Ссылка на рецептуру | FK → recipes.id, CASCADE |
| `name` | String(100) | Название операции | Not Null |
| `sequence_order` | Integer | Порядок выполнения | Not Null, ≥1 |
| `duration_minutes` | Integer | Длительность в минутах | Not Null, >0 |
| `equipment_id` | Integer | Требуемое оборудование | FK → equipment.id, Nullable |
| `competence_id` | Integer | Требуемая квалификация | FK → competences.id, Nullable |

#### Заказы

##### `orders` — Производственные заказы
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `due_date` | Date | Дата выполнения | Not Null |
| `priority` | Integer | Приоритет (1-высокий, 3-низкий) | Default=2, 1-3 |
| `status` | String(20) | Статус: `new`/`planned`/`in_progress`/`done` | Default='new' |
| `created_at` | DateTime | Дата создания | Default=now() |

##### `order_items` — Позиции заказа
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `order_id` | Integer | Ссылка на заказ | FK → orders.id, CASCADE |
| `recipe_id` | Integer | Ссылка на рецептуру | FK → recipes.id, CASCADE |
| `quantity` | Integer | Количество изделий | Not Null, >0 |

#### Производство

##### `stock` — Складские остатки
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `ingredient_id` | Integer | Ссылка на ингредиент | FK → ingredients.id, CASCADE |
| `quantity` | Float | Текущее количество | Not Null, ≥0 |
| `expiry_date` | Date | Дата истечения срока | Nullable |
| `updated_at` | DateTime | Дата последнего обновления | Default=now() |

##### `schedule` — Производственное расписание
| Поле | Тип | Описание | Ограничения |
|------|-----|----------|-------------|
| `id` | Integer | Первичный ключ | PK, Autoincrement |
| `start_time` | DateTime | Начало операции | Not Null |
| `end_time` | DateTime | Окончание операции | Not Null, >start_time |
| `operation_id` | Integer | Ссылка на операцию | FK → operations.id |
| `order_item_id` | Integer | Ссылка на позицию заказа | FK → order_items.id |
| `equipment_id` | Integer | Назначенное оборудование | FK → equipment.id, Nullable |
| `employee_id` | Integer | Назначенный сотрудник | FK → employees.id, Nullable |
| `status` | String(20) | Статус: `scheduled`/`in_progress`/`completed` | Default='scheduled' |
| `is_approved` | Boolean | Утверждён ли план | Default=False |
| `notes` | Text | Примечания планировщика | Nullable |

### Работа с миграциями

```bash
# Применить все миграции
alembic upgrade head

# Откатить последнюю миграцию
alembic downgrade -1

# Создать новую миграцию
alembic revision --autogenerate -m "Описание изменений"

# Проверить статус
alembic current
alembic history
```

### Ингредиенты (`/api/v1/ingredients`)

| Метод | Эндпоинт | Описание | Статусы |
|-------|----------|----------|---------|
| `GET` | `/` | Список ингредиентов (с пагинацией, сортировкой, фильтрацией) | 200 |
| `GET` | `/{id}` | Детали ингредиента по ID | 200, 404 |
| `POST` | `/` | Создать новый ингредиент | 201, 409, 422 |
| `PUT` | `/{id}` | Полностью обновить ингредиент | 200, 404, 409, 422 |
| `DELETE` | `/{id}` | Удалить ингредиент | 204, 404 |
| `GET` | `/check/{name}` | Проверить существование по названию | 200 |
| `POST` | `/import` | Массовый импорт из CSV/JSON | 200 |

**Пример запроса (POST):**
```json
{
  "name": "Мука пшеничная",
  "unit": "кг",
  "shelf_life_days": 365
}
```

**Пример ответа:**
```json
{
  "id": 1,
  "name": "Мука пшеничная",
  "unit": "кг",
  "shelf_life_days": 365
}
```

**Параметры запроса (GET /):**
| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `page` | int | 1 | Номер страницы |
| `limit` | int | 50 | Записей на странице (1-100) |
| `sort_by` | string | name | Поле для сортировки |
| `sort_order` | string | asc | Порядок (asc/desc) |
| `name` | string | - | Фильтр по названию |
| `unit` | string | - | Фильтр по единице измерения |

### Коды ошибок

| Код | Название | Описание | Когда возвращается |
|-----|----------|----------|-------------------|
| `200` | OK | Успешное выполнение | Чтение, обновление |
| `201` | Created | Ресурс создан | Успешное создание (POST) |
| `204` | No Content | Успешное удаление | DELETE без тела ответа |
| `404` | Not Found | Ресурс не найден | Неверный ID в URL |
| `409` | Conflict | Конфликт данных | Дубликат уникального поля (name) |
| `422` | Unprocessable Entity | Ошибка валидации | Некорректные данные в теле запроса |
| `500` | Internal Server Error | Ошибка сервера | Внутренняя ошибка приложения |
